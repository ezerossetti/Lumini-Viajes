# Lumini Viajes

Proyecto web de Lumini Viajes.

- `index.html`: Home principal.
- `style.css`: estilos del proyecto base.
- `script.js`: interacciones.
- `assets/`: recursos.
- `seo/`: páginas SEO.
- `sitemap.xml` y `robots.txt`: SEO técnico.

La navbar de todo el sitio usa el diseño original del proyecto base y suma las secciones que ya estaban definidas: Experiencias y Armá tu viaje.
